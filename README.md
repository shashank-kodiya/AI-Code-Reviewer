## 📖 Overview

**PyInsight AI** is an AI-powered Python code review application that helps developers write cleaner, more efficient, and error-free code. It analyzes Python source code, identifies bugs, suggests improvements, and recommends coding best practices through a simple web interface.

Whether you're a beginner learning Python or an experienced developer, PyInsight AI provides instant feedback to improve code quality and productivity.

---


## ✨ Features

- 🤖 AI-powered Python code review
- 🐞 Detects syntax and logical issues
- 💡 Provides intelligent code improvement suggestions
- 📈 Recommends Python best practices
- ⚡ Fast and interactive web interface
- 🌐 REST API support using Flask
- 🔒 Cross-Origin Resource Sharing (CORS) enabled

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/PyInsight-AI.git
```

```bash
cd PyInsight-AI
```

---

### 2️⃣ Create a Virtual Environment

**Windows**

```bash
python -m venv venv
```

Activate it

```bash
venv\Scripts\activate
```

**Linux/macOS**

```bash
python3 -m venv venv
```

```bash
source venv/bin/activate
```

---

### 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

or

```bash
python -m pip install -r requirements.txt
```

---

### 4️⃣ Configure API Key

Create a `.env` file in the project root.

Example:

```env
OPENAI_API_KEY=your_api_key_here
```

or

```env
GEMINI_API_KEY=your_api_key_here
```

---

### 5️⃣ Run the Application

```bash
python app.py
```

The application will start on

```
http://127.0.0.1:5000
```
